## 📋 配置步骤（必须按顺序执行）

### 步骤1：开通云开发环境 ⚠️

**在微信开发者工具中操作：**

1. 打开微信开发者工具
2. 打开 `zykitchen/kawaii-shop` 项目
3. 点击工具栏的 **"云开发"** 按钮（在顶部菜单栏）
4. 点击 **"开通"**
5. 创建环境：
   - 环境名称：`kawaii-shop`（或其他您喜欢的名称）
   - 计费方式：选择 **"按量计费"**（免费）
   - 确认创建
6. **记录环境ID**（例如：`kawaii-shop-1g2h3j4k5l`）

---

### 步骤2：修改 app.js 中的环境ID

打开 `app.js`，找到第11行：

```javascript
wx.cloud.init({
  env: 'kawaii-shop-xxxxx',  // TODO: 请替换为您的云环境ID
  traceUser: true
});
```

**将 `'kawaii-shop-xxxxx'` 替换为您刚才记录的环境ID**

例如：
```javascript
wx.cloud.init({
  env: 'kawaii-shop-1g2h3j4k5l',  // ← 替换这里
  traceUser: true
});
```

保存文件。

---

### 步骤3：创建数据库集合

**在微信开发者工具中操作：**

1. 点击 **"云开发"** 按钮
2. 进入 **"数据库"**
3. 点击 **"添加集合"**
4. 依次创建以下5个集合：
   - `dishes` （菜品信息）
   - `cart_items` （购物车）
   - `todo_orders` （待做订单）
   - `user_stats` （用户统计）
   - `files` （文件记录，可选）

**每个集合都需要：**
- 点击集合名称
- 点击 **"权限设置"**
- 选择 **"仅创建者可读写"**
- 点击 **"确定"**

---

### 步骤4：上传云函数

**在微信开发者工具中操作：**

1. 在左侧文件树中找到 `cloudfunctions/login`
2. 右键点击 `login` 文件夹
3. 选择 **"上传并部署：云端安装依赖"**
4. 等待上传完成（会显示"上传云函数 login 成功"）

---

## ⚠️ 常见问题

### 问题1：云开发初始化失败
**错误信息：** `云开发初始化失败`

**解决方法：**
1. 检查环境ID是否正确
2. 检查基础库版本 ≥ 2.2.3
3. 确认已开通云开发
4. 重新编译

---

### 问题2：图片上传失败
**错误信息：** `上传失败: xxx`

**解决方法：**
1. 检查网络连接
2. 确认云存储有权限
3. 图片大小不要超过10MB
4. 重新选择图片

---

### 问题3：数据加载失败
**错误信息：** `数据加载失败`

**解决方法：**
1. 检查网络连接
2. 检查云开发环境ID
3. 确认数据库集合已创建
4. 查看控制台详细错误信息

---

### 问题4：添加菜品失败
**错误信息：** `保存失败，请重试`

**解决方法：**
1. 检查数据库"dishes"集合是否已创建
2. 检查集合权限是否为"仅创建者可读写"
3. 查看控制台错误信息
4. 重新编译

---

### 问题5：找不到云函数
**错误信息：** `调用云函数失败`

**解决方法：**
1. 确认已右键上传login云函数
2. 显示"上传成功"才可以
3. 重新上传云函数
