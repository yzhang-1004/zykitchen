# 🐱 喵喵奶茶 - 萌系Kawaii风格小程序

一款超可爱的线下实体店点餐微信小程序，采用Pastel Kawaii视觉风格设计。

## ✨ 项目特色

- 🎨 **马卡龙色系** - 樱花粉、薄荷绿、奶油黄、天空蓝等低饱和度配色
- 🌸 **全圆角设计** - 所有元素采用20rpx-30rpx大圆角，温柔可爱
- 🐾 **Q弹动画** - 按钮点击、加入购物车都有可爱的弹性动效
- 😺 **眨眼吉祥物** - 顶部会眨眼的猫咪图标
- 🛒 **猫窝购物车** - 悬浮购物车按钮设计成猫窝形状

## 🚀 快速开始

### 1. 安装微信开发者工具
下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)

### 2. 导入项目
1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择项目目录：`d:\小程序\kawaii-shop`
4. AppID 选择"测试号"或使用你自己的AppID
5. 点击"导入"

### 3. 运行项目
导入后即可在开发者工具中预览和调试

## 🎨 视觉设计

### 配色方案
```css
--color-primary: #FFB6C1;      /* 樱花粉 */
--color-secondary: #B5EAD7;    /* 薄荷绿 */
--color-accent: #FFDAC1;       /* 奶油橙 */
--color-blue: #C7CEEA;         /* 天空蓝 */
--color-yellow: #FFF5BA;       /* 奶油黄 */
--bg-color: #FFF9F0;           /* 暖米白 */
```

### 动画效果
- **Q弹按钮** - cubic-bezier(0.68, -0.55, 0.265, 1.55) 弹性曲线
- **眨眼动画** - 3秒循环，模拟猫咪眨眼
- **徽章弹出** - 购物车数量变化时的弹性动画

## 🔧 自定义修改

### 修改店铺名称
编辑 `pages/menu/menu.wxml` 第4行：
```html
<view class="shop-title">你的店名</view>
```

### 修改配色
编辑 `app.wxss` 中的CSS变量即可全局修改配色。

### 添加商品数据
编辑 `pages/menu/menu.js` 中的 `products` 对象：
```javascript
products: {
  0: [ // 分类索引
    { 
      id: 1, 
      name: '商品名称', 
      desc: '可爱描述', 
      price: 15, 
      image: '/images/xxx.png' 
    }
  ]
}
```

### 替换图片资源
将图片放入 `images/` 目录，然后修改代码中的图片路径。

## 🎯 技术要点

1. **Flex布局** - 左右分栏、卡片内部布局
2. **CSS变量** - 统一管理配色方案
3. **CSS Animation** - 轻量级动画实现
4. **scroll-view** - 增强滚动性能
5. **rpx单位** - 屏幕自适应
6. **数据驱动** - 分类切换动态更新列表
