# 🍳 ZY厨房 - 使用指南

## 📱 项目简介

ZY厨房是一个面向家庭或小餐厅的菜品管理与点菜系统,融入了游戏化的集星机制,采用温馨的 Kawaii(可爱)风格设计。

---

## ✨ 核心功能

### 1️⃣ 点菜 🍽️
- **分类筛选**: 全部/肉菜🥩/素菜🥬/面食🍜
- **菜品浏览**: 卡片式展示,包含图片、名称、描述
- **加入点单**: 点击"+"按钮添加到点菜篮
- **点菜篮管理**: 
  - 右下角悬浮球显示已点数量
  - 点击展开底部弹窗
  - 可增减数量(- 1 +)
  - 确认后下单,清空点菜篮

### 2️⃣ 管理 🍳
- **菜品CRUD**:
  - ➕ 新增菜品(名称、分类、描述、图片、菜谱)
  - ✏️ 编辑已有菜品
  - 🗑️ 删除菜品(二次确认)
- **做菜得星星** ⭐:
  - 点击"做这道菜👨‍🍳"按钮
  - 触发烹饪动画
  - 获得1颗星星
  - 记录烹饪历史

### 3️⃣ 我的 ⭐
- **星星罐子**: 动态显示收集的星星总数
- **成就头衔**:
  - 🐣 厨房小当家 (0-5颗)
  - 🪄 美味魔法师 (6-15颗)
  - 👨‍🍳 米其林大厨 (16-30颗)
  - 👑 传奇食神 (30+颗)
- **成就进度**: 可视化展示解锁进度
- **烹饪记录**: 按时间倒序展示做菜历史

## 🚀 快速开始

### 1. 导入项目
1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择项目目录: `d:\miniprogram\kawaii-shop`
4. AppID 选择"测试号"或使用你自己的AppID
5. 点击"导入"

### 2. 运行项目
导入后即可在开发者工具中预览和调试

### 3. TabBar 图标说明
项目已生成占位图标(1x1像素),建议替换为正式图标:
- 位置: `/images/` 目录
- 需要6个文件:
  - `tab-order.png` / `tab-order-active.png`
  - `tab-manage.png` / `tab-manage-active.png`
  - `tab-profile.png` / `tab-profile-active.png`
- 推荐尺寸: 81x81px
- 可以从 [iconfont.cn](https://www.iconfont.cn/) 下载

## 💡 数据流转

### 全局数据结构 (app.globalData)
```javascript
{
  dishes: [],           // 菜品列表
  cartItems: [],        // 点菜篮 [{dish, quantity}]
  starCount: 0,         // 星星总数
  cookHistory: []       // 烹饪记录 [{dishName, time, stars}]
}
```

### 点菜流程
1. 用户在 order 页面点击"加入点单"
2. 数据写入 `globalData.cartItems`
3. 悬浮球实时更新数量
4. 点击悬浮球展开点菜篮弹窗
5. 确认下单后清空 `cartItems`

### 做菜得星星流程
1. 用户在 manage 页面点击"做这道菜👨‍🍳"
2. 显示"烹饪中..."加载提示
3. 800ms后:
   - `globalData.starCount + 1`
   - 菜品 `cookCount + 1`
   - 添加记录到 `globalData.cookHistory`
4. 显示 Toast: "恭喜获得一颗小星星⭐"

## 🔧 自定义修改

### 修改店铺名称
编辑 `app.json`:
```json
{
  "window": {
    "navigationBarTitleText": "你的店名"
  }
}
```

### 修改配色
编辑 `app.wxss` 中的 CSS 变量即可全局修改配色。

### 添加更多菜品
编辑 `app.js` 的 `onLaunch()` 方法,在 `this.globalData.dishes` 数组中添加新菜品对象。

### 调整成就头衔
编辑 `pages/profile/profile.js` 的 `loadData()` 方法中的头衔判断逻辑。

## 🎯 技术要点

1. **TabBar 导航**: 底部三栏切换
2. **Flex 布局**: 响应式设计
3. **CSS 变量**: 统一管理配色
4. **CSS Animation**: 轻量级动画
5. **scroll-view**: 增强滚动性能
6. **rpx 单位**: 屏幕自适应
7. **数据驱动**: globalData 全局状态管理
8. **条件渲染**: wx:if 控制显示
9. **列表渲染**: wx:for 遍历数据
