# 🗑️ 菜品删除功能修复方案

## 📋 问题描述

**现象：** 点击删除按钮无法删除菜品

## 🔍 问题分析

**根本原因：wxml 与 JS 参数不匹配**

### wxml（第125行）：
```html
<!-- 传递的是 data-id -->
<view class="action-btn delete-btn" bindtap="deleteDish" data-id="{{item.id}}" hover-class="btn-hover">
```

### JS（第475行）：
```javascript
// 读取的是 data-dish（整个对象）
deleteDish(e) {
  const dish = e.currentTarget.dataset.dish;  // ❌ undefined！
  // dish 是 undefined，所以无法删除
}
```

**结果：** `dish` 为 `undefined`，导致：
- `dish._id` 报错（Cannot read property '_id' of undefined）
- 删除逻辑根本没有执行
- 弹窗确认后就卡住了

## 💡 修复方案

**两种修复方式，选其一：**

### 方案A：修改 wxml（推荐）⭐

把 `data-id` 改为 `data-dish`，传递整个对象，与其他按钮保持一致：

```html
<!-- 修改前 -->
<view class="action-btn delete-btn" bindtap="deleteDish" data-id="{{item.id}}" hover-class="btn-hover">

<!-- 修改后 -->
<view class="action-btn delete-btn" bindtap="deleteDish" data-dish="{{item}}" hover-class="btn-hover">
```

**优点：**
- ✅ 只改一行 wxml
- ✅ 与 cookDish、openEditDish 传参方式一致
- ✅ JS 逻辑无需修改

### 方案B：修改 JS

保持 wxml 不变，修改 JS 读取 `data-id`，然后从 dishes 中找到对应菜品：

```javascript
deleteDish(e) {
  const id = e.currentTarget.dataset.id;  // 读取 id
  const dishes = app.globalData.dishes || [];
  const dish = dishes.find(d => d.id === id);  // 找到菜品
  
  if (!dish) {
    wx.showToast({ title: '菜品不存在', icon: 'none' });
    return;
  }
  
  // 继续删除逻辑...
}
```

**优点：**
- ✅ wxml 无需修改

**缺点：**
- ⚠️ 需要多一步查找
- ⚠️ 与其他按钮风格不统一

## ✅ 推荐方案

**使用方案A：修改 wxml，将 `data-id` 改为 `data-dish`**

- 只需改一行
- 与其他按钮风格统一
- JS 逻辑完全不用动

## 📝 修改内容

**文件：** `pages/manage/manage.wxml` 第125行

```html

<!-- 修改后 -->
<view class="action-btn delete-btn" bindtap="deleteDish" data-dish="{{item}}" hover-class="btn-hover">
```
