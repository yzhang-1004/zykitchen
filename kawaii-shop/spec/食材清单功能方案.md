# 食材清单功能方案

> 版本：v1.3 | 日期：2025-06-08

---

## 1. 需求描述

做菜时（管理页待做区），除了菜谱步骤，还需要显示**食材清单**。
当有多个待做菜品时，顶部额外显示**汇总采购清单**，每个食材标注对应的菜名，方便一次性采购。

---

## 2. 现状分析

### 当前数据结构
- `dishes` 集合：有 `recipe` 字段（文本，步骤用 `\n` 分隔）
- **没有 `ingredients` 字段**

### 当前 UI 流程
```
点菜页 → 加入购物车 → 确认下单 → 生成待做订单（含 recipeSteps）
管理页 → 待做区 → 展开卡片 → 显示菜谱步骤 + "做完了"/"取消"按钮
```

---

## 3. 方案设计

### 3.1 数据模型

**dishes 集合新增字段：**
```javascript
{
  // ... 现有字段
  ingredients: ["土豆", "青椒", "盐", "醋"]  // 只存食材名称，不存用量
}
```
- 类型：字符串数组
- 只存名称，用量在做菜时自行判断
- 空菜品默认 `[]`

**todo_orders 集合新增字段：**
```javascript
{
  // ... 现有字段
  ingredients: ["土豆", "青椒", "盐"]  // 下单时从 dish 复制
}
```

### 3.2 编辑菜品 — 新增食材输入区

在现有编辑弹窗中，**菜谱做法（recipe）** 上方新增 **“食材清单”** 输入区：

```
┌─────────────────────────────┐
│ 菜品图片（最多3张）           │
│ [img] [img] [+]             │
│                             │
│ 🛒 食材清单                  │
│ ┌──────────┐ [×]            │
│ │ 土豆      │               │
│ └──────────┘                │
│ ┌──────────┐ [×]            │
│ │ 青椒      │               │
│ └──────────┘                │
│ [+ 添加食材]                 │
│                             │
│ 📖 菜谱做法                  │
│ ┌───────────────────┐       │
│ │ 1. 土豆切丝...     │       │
│ └───────────────────┘       │
└─────────────────────────────┘
```

**交互方式：**
- 每条食材一行，用 `<input>` 输入（只输名称）
- 右侧有删除按钮 `[×]`
- 底部有 `[+ 添加食材]` 按钮
- 最多 20 条

### 3.3 管理页待做区 — 汇总采购清单 + 单菜品食材

#### 汇总采购清单（独立卡片，与待做菜品并列）

```
┌─────────────────────────────┐
│ 🛒 采购清单                  │
│  土豆  青椒  牛肉  盐  酱油  │
└─────────────────────────────┘

┌─────────────────────────────┐
│ 📝 待做菜品            (3)  │
│ 点菜后这里会显示待做清单哦~  │
├─────────────────────────────┤
│ [酸辣土豆丝卡片]             │
│ [土豆炖牛肉卡片]             │
└─────────────────────────────┘
```

**汇总规则：**
- 遍历所有待做订单的 `ingredients`
- 按食材名去重（使用 Set）
- 只显示食材名，不显示对应菜名
- 只有 1 个待做菜品时也显示采购清单
- 待做为空时不显示采购清单
- **旧订单回退逻辑**：如果订单没有 `ingredients` 字段，自动回退到 `order.dish.ingredients`

#### 单菜品展开面板

```
┌─────────────────────────────┐
│ 酸辣土豆丝          肉菜 ▾  │
├─────────────────────────────┤
│ 🛒 食材                      │
│  ● 土豆  ● 青椒  ● 盐  ● 醋 │
│                             │
│ 📖 做法                      │
│  ● 土豆切丝泡水              │
│  ● 热油爆炒...               │
├─────────────────────────────┤
│ [👨‍🍳 做完了]  [🗑️ 取消]     │
└─────────────────────────────┘
```

- 食材用标签（tag）样式横向排列，紧凑
- 无食材时显示"暂无食材清单"

### 3.4 下单流程

**order.js confirmOrder：**
- 创建 todo_orders 时，从 `item.dish.ingredients` 复制食材到订单

### 3.5 点菜页购物车弹窗

当前购物车弹窗展开菜谱时，同样在步骤上方显示食材标签（与待做区单菜品一致）。
购物车弹窗**不显示汇总采购清单**（那是管理页的功能）。

---

## 4. 改动文件清单

| 文件 | 改动 |
|------|------|
| `pages/manage/manage.wxml` | 编辑弹窗加食材输入区；待做区顶部加汇总采购清单；展开面板加食材标签 |
| `pages/manage/manage.js` | formData 加 ingredients；submitDish 存食材；openEditDish 加载食材；计算汇总采购清单 |
| `pages/manage/manage.wxss` | 食材输入样式；采购清单样式；食材标签样式 |
| `pages/order/order.js` | confirmOrder 传递 ingredients 到 todo_orders |
| `pages/order/order.wxml` | 购物车弹窗展开时显示食材标签 |
| `pages/order/order.wxss` | 食材标签样式 |

**不涉及数据库结构变更**（ingredients 只是 dishes 文档的新字段，无需新建集合）。

---

## 5. 兼容性

- **旧菜品**：没有 `ingredients` 字段 → 默认 `[]`，显示"暂无食材清单"
- **旧待做订单**：没有 `ingredients` → 默认 `[]`，汇总清单中不显示
- 无需数据迁移

---
