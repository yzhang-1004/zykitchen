# 🖼️ 图片存储方案（绕开云存储权限）

## 📋 问题分析

**现状：**
- 云存储权限修改需要付费版
- `getTempFileURL()` 也受权限限制（`STORAGE_EXCEED_AUTHORITY`）
- 免费版所有云存储操作都只有创建者可访问
- 无法实现跨设备查看图片

## 💡 解决方案：图片 Base64 存入数据库

**核心思路：**
- 不上传到云存储
- 将图片压缩后转成 base64 字符串
- 直接存入云数据库的 `images` 字段
- 读取时直接使用 base64，无需转换

**优点：**
- ✅ 免费，无需升级付费版
- ✅ 绕开所有云存储权限限制
- ✅ 所有人读取数据库就能看到图片
- ✅ 实现简单，无需额外API调用

**缺点：**
- ⚠️ 数据库单条记录有大小限制（16MB，图片base64一般远小于此）
- ⚠️ 图片需要压缩（控制每张 < 100KB）

## 🎯 实施步骤

### 步骤1：添加图片压缩方法

**在 `utils/upload.js` 中添加：**

```javascript
/**
 * 压缩图片并转base64
 * @param {string} filePath 本地文件路径
 * @param {number} maxWidth 最大宽度（默认800）
 * @param {number} quality 压缩质量（默认0.6）
 * @returns {Promise<string>} base64字符串
 */
function compressImageToBase64(filePath, maxWidth = 800, quality = 0.6) {
  return new Promise((resolve, reject) => {
    // 1. 获取图片信息
    wx.getImageInfo({
      src: filePath,
      success: (info) => {
        // 2. 计算压缩后的尺寸
        let width = info.width;
        let height = info.height;
        if (width > maxWidth) {
          height = Math.round(height * maxWidth / width);
          width = maxWidth;
        }
        
        // 3. 使用canvas压缩
        const canvas = wx.createOffscreenCanvas({
          type: '2d',
          width: width,
          height: height
        });
        
        // 微信不支持OffscreenCanvas的2d context，改用wx.compressImage
        wx.compressImage({
          src: filePath,
          quality: quality * 100,
          success: (res) => {
            // 4. 读取压缩后的文件为base64
            const fs = wx.getFileSystemManager();
            try {
              const base64 = fs.readFileSync(res.tempFilePath, 'base64');
              // 添加data URI前缀
              const dataURI = `data:image/jpeg;base64,${base64}`;
              console.log('图片压缩完成，大小约:', Math.round(base64.length * 0.75 / 1024), 'KB');
              resolve(dataURI);
            } catch (err) {
              console.error('读取base64失败:', err);
              reject(err);
            }
          },
          fail: (err) => {
            console.error('压缩图片失败:', err);
            reject(err);
          }
        });
      },
      fail: reject
    });
  });
}
```

### 步骤2：修改 uploadImages 方法

**改为返回 base64 而不是云存储路径：**

```javascript
async function uploadImages(filePaths, folder = 'dish') {
  const results = [];
  for (const path of filePaths) {
    if (path.startsWith('cloud://')) {
      // 已经是云存储路径，保留
      results.push(path);
    } else if (path.startsWith('data:')) {
      // 已经是base64，保留
      results.push(path);
    } else {
      // 本地图片，压缩并转base64
      try {
        const base64 = await compressImageToBase64(path);
        results.push(base64);
      } catch (err) {
        console.error('图片处理失败:', err);
      }
    }
  }
  return results;
}
```

## ⚠️ 注意事项

```

远小于16MB，完全没问题！
```
