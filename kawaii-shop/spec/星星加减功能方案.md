# ⭐ 星星加减功能方案

## 📋 需求描述

在"我的"页面中，用户可以手动增加或减少星星数量。

## 🔍 现状分析

**当前逻辑：**
- 星星只能通过"做菜"获得（manage.js 中的 `completeTodo`）
- 每做一道菜 +1 颗星
- 没有手动修改星星的功能

**星星存储位置：**
- `app.globalData.starCount` - 内存数据
- 云数据库 `user_stats` 集合 - 持久化存储

## 💡 功能设计

### UI 设计

在星星罐子区域添加 + / - 按钮：

```
┌─────────────────────────┐
│    我的厨房 ⭐            │
├─────────────────────────┤
│                         │
│        🏺               │
│    [-]  12 颗星星  [+]   │
│                         │
└─────────────────────────┘
```

- `[-]` 按钮：减少1颗星星
- `[+]` 按钮：增加1颗星星
- 星星数量不能小于0

### 交互设计

**增加星星：**
1. 点击 `[+]` 按钮
2. 星星数 +1
3. 同步到云数据库
4. 更新头衔显示

**减少星星：**
1. 点击 `[-]` 按钮
2. 如果星星数 > 0：星星数 -1，同步到云端，更新头衔
3. 如果星星数 = 0：提示"已经是0颗星星了~"

### 2. 修改 profile.js

添加加减星星方法：

```javascript
const db = require('../../utils/db');

Page({
  // ... 现有代码

  // 增加星星
  async increaseStar() {
    const newCount = this.data.starCount + 1;
    await this.updateStarCount(newCount);
  },

  // 减少星星
  async decreaseStar() {
    if (this.data.starCount <= 0) {
      wx.showToast({
        title: '已经是0颗星星了~',
        icon: 'none'
      });
      return;
    }
    const newCount = this.data.starCount - 1;
    await this.updateStarCount(newCount);
  },

  // 更新星星数（本地+云端）
  async updateStarCount(newCount) {
    // 1. 更新本地数据
    app.globalData.starCount = newCount;
    
    // 2. 重新计算头衔
    this.loadData();
    
    // 3. 同步到云数据库
    try {
      const result = await db.get('user_stats', {}, 1);
      if (result.success && result.data.length > 0) {
        await db.update('user_stats', result.data[0]._id, {
          starCount: newCount
        });
      }
    } catch (err) {
      console.error('同步星星数失败:', err);
    }
  }
});
```
