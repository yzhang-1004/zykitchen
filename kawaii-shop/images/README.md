# TabBar 图标说明

由于微信小程序 TabBar 需要图标文件,请准备以下 6 个 PNG 图标(建议尺寸: 81x81px):

## 点菜 Tab
- `tab-order.png` - 点菜图标(未选中)
- `tab-order-active.png` - 点菜图标(选中,粉色)

## 管理 Tab  
- `tab-manage.png` - 管理图标(未选中)
- `tab-manage-active.png` - 管理图标(选中,粉色)

## 我的 Tab
- `tab-profile.png` - 我的图标(未选中)
- `tab-profile-active.png` - 我的图标(选中,粉色)

## 临时解决方案

如果暂时没有图标,可以:
1. 使用 emoji 表情截图作为临时图标
2. 或者使用简单的几何图形
3. 从 iconfont.cn 下载合适的图标

## 图标放置位置
将所有图标文件放在 `/images/` 目录下即可。
